# 🚀 Featured Projects

## 🧠 Chat-Brain — AI YouTube Live Chat Assistant

A local AI-powered YouTube Live Chat assistant that reads live chat messages, processes relevant messages using a local LLM, and posts conversational replies back to YouTube.

### ✨ Features

* 📺 Reads YouTube Live Chat
* 🤖 Local LLM using Ollama
* 💬 Automatically replies to relevant messages
* 🌐 Supports English, Hindi, Marathi & Hinglish
* 🧠 Smart reply filtering
* 📊 Streamlit dashboard
* 🔐 Google OAuth authentication
* 💾 Local chat history
* 🖥️ One-click Windows startup

### 🛠️ Technologies

`Python` `Ollama` `LangChain` `YouTube Data API` `Streamlit` `Google OAuth`

🔗 **Repository:**
https://github.com/Sp-4030/Chat-Brain
